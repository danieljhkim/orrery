# Shear-consumption lattice

This apparatus tests the frozen local destruction rule

`s = n sqrt((3/2) e_dev:e_dev)`

with coefficient exactly one. The primary spherical finite-volume lattice
moves substrate between neighbouring shells down density gradients. Its flow
speed is measured from that local transported flux; no radial velocity profile
is supplied. A fixed inward flux at the core anchors the flow, a unit-density
outer reservoir replenishes it, and every shell destroys substrate from the
anisotropic strain calculated from adjacent face speeds. Semi-implicit steps
evolve density to a declared steady tolerance.

Run:

```text
uv run lab/sims/shear-consumption-lattice/main.py
```

The command deterministically rewrites `summary.json` and
`runs/2026-08-12-seed-42.json`. Add `--check-determinism --no-write` for a
byte-for-byte in-memory rerun check. The run record is authoritative for all
full-precision measurements and convergence data.

## Predeclared gates

The primary attractor measurement uses 256 shells, `dt=0.1`, a core flux of
`0.0001`, and radii 3–20. It is repeated from a uniform rest state and from a
seeded, noisy depleted state. Shell counts 128/256/512 and time steps
0.2/0.1/0.05 provide the spatial and step-halving checks. The measured values
below are generated by `main.py`; theory-level reconciliation remains outside
this repository.

- **Attractor:** see `summary.json` for the fitted exponent, regression error,
  combined numerical error, and convergence arrays. The pass criterion requires
  the target `-1/2` to lie within two combined regression, seed, resolution,
  and timestep errors, with all runs at the steady tolerance.
- **Amplitude:** five imposed core fluxes are fitted to an exterior
  `A r^-1/2` template. The gate requires strictly monotone amplitude and less
  than `1e-6` relative spread between the two initial conditions.
- **Silence:** a manufactured 17-cubed uniformly expanding lattice is evaluated
  by the same 3-D deviatoric-strain stencil. Its measured consumption must be
  below `1e-12` relative to `n|H|`.

## Exploratory two-core probe

A full 25-cubed Cartesian companion lattice uses the identical neighbour-flux
and 3-D strain rule. One core is held fixed while a second core's rate is swept.
Paired velocity subtraction isolates the target core over radii 2–5. The run
record reports the measured modulation, a fitted two-parameter law, and the
direct comparison with the ORB-10157 screening family
`A(D) = (1-D)^1.071`. This probe is explicitly exploratory, not a gate; its
coarse-grid limitation is retained in the report.

Finite density depletion shifts stronger-core radial fits slightly below the
weak-depletion half-power limit. The primary gate therefore tests the declared
weak-depletion attractor, while the amplitude sweep preserves the stronger
branches rather than hiding that systematic.
